====================================================================
THE MARK - WHAT IT MEANS
====================================================================

A hexagonal fort keep with battlements, hollow, holding three stacked
data layers. Fort plus data. It reads as the product thesis in one
shape: the lead list lives inside the walls, not in a file on someone
laptop.

Worth keeping in mind for the UI - the mark already says "contained",
so the interface does not need to shout about security. Let the
product feel calm and let the audit log do the talking.


====================================================================
USAGE RULES
====================================================================

  CLEAR SPACE
    Keep free space around the mark equal to the height of one
    battlement notch, roughly 14 units in the SVG viewBox.

  MINIMUM SIZE
    Icon:   24 px. Below this the data layers merge - use a
            simplified favicon instead.
    Lockup: 120 px wide. Below this drop the wordmark and use the
            icon alone.

  BACKGROUNDS
    Light background   -> datafort-icon.svg (full colour)
    Off-white surface  -> datafort-icon.svg (full colour)
    Navy background    -> datafort-icon-mono.svg with color:#fff
    Black background   -> datafort-icon-mono.svg with color:#fff
    Photo / busy image -> mono white only, never full colour

  DO NOT
    - Recolour the mark outside the palette above
    - Stretch, skew, rotate or add effects
    - Place the full-colour mark on a dark background
    - Rebuild the wordmark in a different typeface
    - Use the mark as a watermark on lead screens. The security
      watermark is per-user text, not the logo. See requirements 7.3.


====================================================================
TYPOGRAPHY
====================================================================

  The wordmark in the original is a heavy geometric sans, all caps,
  lightly letter-spaced. It is close to Poppins Bold or Montserrat
  Bold but has NOT been confirmed.

  ASK THE DESIGNER which typeface it is. Until then:

  - datafort-lockup.svg uses live text with a font stack, so it will
    render differently on machines without the font installed.
  - Before production, either convert the wordmark to outlined paths
    or self-host the correct webfont.
  - Never ship the lockup as live text to end users. A missing font
    means a broken logo.

  SUGGESTED UI TYPE (separate from the logo):
    Headings  Poppins or Montserrat, 600
    Body      Inter or system-ui, 400/500
    Numeric   tabular-nums for quota counters and audit timestamps
