====================================================================
PRODUCT vs COMPANY  -  READ THIS FIRST
====================================================================

  Datafort is the PRODUCT. FolksFirst Labs is the COMPANY.

  The artwork in logo.png is the FolksFirst Labs logo and it contains
  a FOLKSFIRST LABS wordmark. That wordmark is NOT used anywhere in
  the Datafort UI. The app uses:

      the FolksFirst hexagon MARK   +   "DATAFORT" as live text

  in the sidebar and on the login panel. Everything the product says
  about itself - page titles, body copy, the login footer - says
  Datafort.

  So: if you are placing a logo inside the app, you want
  logo-mark-light.png, not any of the full lockups. The lockups exist
  for company-level material (website, email header, decks), which is
  a different surface with a different owner.

  Status New      #2a6fe0    "New" lead badges.

  DANGER SHARES THE BRAND HUE - READ THIS
    Brand red and alert red are the same family, so they cannot be
    told apart by colour alone. The system separates them by
    TREATMENT instead, and that separation is load-bearing:

      Brand red  -> solid fills only. Primary button, active nav.
      Alert red  -> tint, outline or transient toast. Never a solid
                    fill competing with a primary button.

    .alert--error and .badge--lost are already built this way (8-11%
    background, red text). There is no .btn--danger class - the button
    set is .btn--primary / .btn--ghost / .btn--block only. If one is
    ever added, build it as a ghost with red text, NOT a solid red
    fill: a solid red destructive button is indistinguishable from the
    primary Save button and the danger signal is gone.

  "NEW" IS NOT BRAND RED
    Status new and status lost sit in the same table column, so new
    keeps the blue #2a6fe0 (#4d8ef5 dark) it has always had rather
    than inheriting the brand tint. That value is shared with
    STATUS.new in charts.js so a status reads the same as a badge and
    as a chart segment. The categorical chart series are likewise NOT
    rebranded - they are validated for colour-vision separation and
    are independent of brand colour by design.

====================================================================
THE MARK - WHAT IT MEANS
====================================================================

Two chevrons meeting in a hexagon, with a single person at the centre
of it. Folks first: the structure exists around the individual, not
the other way round.

For the UI this means what the old note said, and it is still true -
the mark already says "contained", so the interface does not need to
shout about security. Let the product feel calm and let the audit log
do the talking.


====================================================================
USAGE RULES
====================================================================

  INSIDE THE APP
    Mark only, plus "DATAFORT" as live text in --font-head. Never the
    FolksFirst wordmark. See .side__brand in app.css and
    .brandside__logo in login.css.

  BACKGROUNDS
    Light background   -> logo.png / logo-mark.png
    Dark chrome        -> logo-light.png / logo-mark-light.png
    Photo / busy image -> knockout only

    Never place the full-colour artwork on a dark background. Its
    inner figure and wordmark are near-black and simply disappear -
    that is the exact reason the knockout variants exist.

  WHICH ORIENTATION (company material only)
    Stacked is the primary lockup - use it wherever there is vertical
    room. Horizontal is for wide, short spaces.

  MINIMUM SIZE
    Mark:   24 px. Below this the centre figure fills in - use
            favicon.ico, which is built for it.
    Lockup: 120 px wide. Below this drop the wordmark and use the
            mark alone.

  CLEAR SPACE
    Keep free space around the mark equal to the width of one chevron
    arm, roughly 12% of the mark height.

  DO NOT
    - Recolour the mark outside the palette above
    - Stretch, skew, rotate or add effects
    - Place the full-colour lockup on a dark background
    - Put the FOLKSFIRST LABS wordmark in the product UI
    - Use the mark as a watermark on lead screens. The security
      watermark is per-user text, not the logo. See requirements 7.3
      and the header comment in watermark.js.


====================================================================
TYPOGRAPHY
====================================================================

  The wordmark inside logo.png is outlined pixels, not live text, so
  it cannot break on a machine without the font.

  The "DATAFORT" wordmark in the app IS live text, set in --font-head
  (Poppins 700, 1 px tracking). That is deliberate: it inherits
  currentColor for the dark chrome and costs no extra request. Poppins
  is already loaded on every page. If that ever changes, outline it.

  UI type:
    Headings  Poppins or Montserrat, 600
    Body      Inter or system-ui, 400/500
    Numeric   tabular-nums for quota counters and audit timestamps
