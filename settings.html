Export

There is no export, and it cannot be switched on. Datafort has no endpoint that returns leads as a file — not for reps, not for administrators, not for support staff. This is enforced in the backend rather than hidden in the interface, so it holds even against a crafted request.

If you leave Datafort, contact support for a supervised data handover. It is a manual, logged, identity-verified process — deliberately not a button.
